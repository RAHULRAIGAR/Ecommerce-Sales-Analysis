## 📌 Project Overview

This project focuses on analyzing e-commerce sales data to uncover meaningful insights into revenue trends, customer purchasing patterns, and overall business performance.

The dashboard transforms raw sales data into an interactive and visually engaging analytical experience, making it easier to understand business performance and identify valuable insights.

---

## ✨ Key Features

- 📈 **Sales Performance Analysis** – Explore sales trends and revenue patterns.
- 📅 **Monthly Sales Trends** – Analyze sales performance over time.
- 👥 **Customer Analytics** – Identify top customers based on revenue.
- 📊 **Interactive Visualizations** – Explore insights through interactive charts.
- 🔍 **Exploratory Data Analysis** – Understand data patterns and distributions.
- 🎯 **Business Insights** – Support data-driven decision-making.

## 🚀 Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/RAHULRAIGAR/Ecommerce-Sales-Analysis.git
```

### 2. Navigate to Project Directory

```bash
cd Ecommerce-Sales-Analysis
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Launch the Dashboard

```bash
streamlit run app.py
```

Open your browser at:

```text
http://localhost:8501
```
